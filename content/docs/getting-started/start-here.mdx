If you feel lost, start HERE.

This is the recommended ToonUI learning path from beginning to end.

## The right order

Follow these pages in this exact sequence:

1. **[Overview](/docs)** — understand what ToonUI is and what it is NOT
2. **[Choose Your Integration Path](/docs/getting-started/choose-your-integration-path)** — decide package path, framework path, and AI loop
3. **[Installation](/docs/getting-started/installation)** — choose the correct package path
4. **[Quickstart](/docs/getting-started/quickstart)** — make ToonUI work end to end
5. **[Configuration](/docs/getting-started/configuration)** — understand the main moving parts
6. **[Mental Model](/docs/concepts/mental-model)** — learn the architecture boundary
7. **[Syntax](/docs/language/syntax)** — learn the core writing rules
8. **[Node Reference](/docs/language/node-reference)** — understand when to use each node
9. **[AI Authoring Rules](/docs/language/ai-authoring-rules)** — learn how models should behave
10. **[Complete Syntax Reference](/docs/language/complete-syntax-reference)** — use as deep reference, not as first reading

## What to read first vs later

| Read first | Read later |
|---|---|
| Overview | Full Generated Prompt |
| Installation | Catalog |

| Configuration | React Runtime and Hooks |
| Mental Model | Errors and Validation |

## The correct mindset

Do NOT start with:

- full syntax reference
- prompt internals
- low-level reference pages
- every package page at once

Start with the flow that gets ToonUI working first.

Then deepen your understanding.
